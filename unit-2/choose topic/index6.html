Magazine Layout Flow

1. Curving Around a Circle

This block of copy is curving directly around a red circle element. By setting the shape-outside property to a circle value, the browser's typographic renderer stops aligning words to a straight, vertical line. Instead, it measures the layout boundaries using the circle's exact geometric math radius, shifting the words inward dynamically to hug the edge.

2. Sliding Down a Polygon (Triangle)

This block of text demonstrates wrapping along a hard diagonal line. Using a polygon coordinate matrix layout map, we carved a triangular shape out of the space. Notice how the text drops step-by-step along the hypotenuse of the right-angle wedge shape, mimicking structural modern editorial design formats found in high-end fashion print layouts.

3. Mapping Around Image Alpha Transparency

Finally, you can pass actual transparent images directly into the browser layout engine. By pointing the shape-outside variable toward a PNG file path containing clear alpha channels, the system evaluates where solid pixels begin. This allows regular paragraph blocks to wrap tightly against irregular silhouettes like stars, products, or human shapes.
